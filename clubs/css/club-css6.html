شرح خصائص CSS

display: grid

display: grid; → يحول العنصر إلى شبكة (Grid Container)

بدونها ما تشتغل خاصيات الـ Grid


.container {
    display: grid;
}

grid-template-columns

grid-template-columns: 1fr 1fr 1fr; → يحدد عدد وعرض الأعمدة

  • 1fr → جزء من المساحة المتاحة (fraction)
  • 300px → عرض ثابت بالبكسل
  • auto → يأخذ عرض المحتوى

  .container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;  /* 3 أعمدة متساوية */
}

position: absolute;

المعنى: العنصر يخرج من التدفق الطبيعي للصفحة ويوضع بالنسبة لأقرب عنصر أب عنده position: relative

الخصائص المرافقة: top, bottom, left, right


.one {
    position: absolute;
    top: 20px;
    left: 20px;
}

gap / column-gap / row-gap

gap: 1rem 2rem; → مسافة بين الأعمدة والصفوف

  • column-gap → مسافة بين الأعمدة
  • row-gap → مسافة بين الصفوف
  • gap: 1rem; → نفس المسافة للأعمدة والصفوف
  • gap: 1rem 2rem; → الأول للصفوف، الثاني للأعمدة

 .container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 1rem;           /* مسافة متساوية */
    /* أو */
    row-gap: 1rem;       /* مسافة بين الصفوف */
    column-gap: 2rem;    /* مسافة بين الأعمدة */
}

grid-template-rows

grid-template-rows: auto 200px auto; → يحدد ارتفاع الصفوف

  • auto → يأخذ ارتفاع المحتوى
  • 200px → ارتفاع ثابت
  • 1fr → جزء من المساحة المتاحة

.one .container {
    display: grid;
    grid-template-rows: auto 200px auto;
}

الفرق بين auto و 1fr

  • auto → يأخذ حجم المحتوى فقط
  • 1fr → يأخذ المساحة المتاحة بعد توزيع الـ auto
  • 1fr أقوى → يأخذ المساحة الزائدة

/* 1fr يأخذ المساحة الزائدة */
.container {
    display: grid;
    grid-template-columns: auto 1fr auto;  /* وسط يتمدد */
}

grid-column / grid-row

يتحكم في مكان وامتداد العنصر داخل الشبكة

  • grid-column: 1 / span 2; → يمتد على عمودين
  • grid-row: 1 / span 2; → يمتد على صفين

.item {
    grid-column: 1 / span 2;  /* يمتد على عمودين */
    grid-row: 1 / span 2;     /* يمتد على صفين */
}

Media Query (استجابة الجوال)

@media (max-width: 767px) → يغير التنسيق عندما يكون عرض الشاشة أقل من 767px


/* للشاشات الكبيرة */
.container {
    grid-template-columns: 1fr 1fr 1fr;
}

/* للجوال */
@media (max-width: 767px) {
    .container {
        grid-template-columns: 1fr;  /* عمود واحد */
    }
}
