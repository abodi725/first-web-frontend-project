القائمة المنسدلة (Dropdown Menu)

الفكرة:

  • القائمة تكون مخفية في البداية
  • عند تمرير الماوس على الزر أو السهم → تظهر القائمة
  • عند إبعاد الماوس → تختفي القائمة

الخصائص المستخدمة:

  • display: none; → يخفي القائمة ويزيل مكانها
  • display: block; → يظهر القائمة
  • position: absolute; → القائمة تخرج من التدفق (ما تدفش العناصر اللي تحتها)
  • top: 100%; → القائمة تظهر تحت الزر مباشرة
  • z-index: 1; → القائمة تظهر فوق العناصر الثانية
  • .dropdown:hover .dropdown-content → يحدد عنصر القائمة عند hover على الحاوية 

<div class="dropdown">
    <button class="dropbtn">القائمة ▼</button>
    <div class="dropdown-content">
        <a href="#">🏠 الرئيسية</a>
        <a href="#">👤 من نحن</a>
        <a href="#">🛠️ خدماتنا</a>
        <a href="#">📞 اتصل بنا</a>
    </div>
</div> 
        

/* الحاوية الرئيسية */
.dropdown {
    position: relative;
    display: inline-block;
}

/* الزر */
.dropbtn {
    background-color: #6C63FF;
    color: white;
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    cursor: pointer;
    font-size: 16px;
    transition: 0.3s;
}

/* القائمة - مخفية في البداية */
.dropdown-content {
    display: none;
    position: absolute;
    top: 100%;
    right: 0;
    background-color: #1a1a2e;
    min-width: 180px;
    border-radius: 8px;
    box-shadow: 0 8px 16px rgba(0,0,0,0.3);
    z-index: 1;
}

/* روابط القائمة */
.dropdown-content a {
    color: white;
    padding: 12px 16px;
    text-decoration: none;
    display: block;
    transition: 0.3s;
}

/* تأثير hover على الروابط */
.dropdown-content a:hover {
    background-color: #6C63FF;
    border-radius: 8px;
}

/* إظهار القائمة عند hover */
.dropdown:hover .dropdown-content {
    display: block;
}

/* تأثير hover على الزر */
.dropdown:hover .dropbtn {
    background-color: #FF6584;
}

أنواع القوائم المنسدلة (Dropdown Menu)

🔹 النوع 1: القائمة تنزل لتحت (Down)

  • تظهر أسفل الزر مباشرة
  • تستخدم top: 100%;

<div class="dropdown-item">
    <h3>▼ نزول لتحت</h3>
    <div class="dropdown dropdown-down">
        <button class="dropbtn">القائمة ▼</button>
        <div class="dropdown-content">
            <a href="#">الرئيسية</a>
            <a href="#">من نحن</a>
            <a href="#">الخدمات</a>
            <a href="#">اتصل بنا</a>
        </div>
    </div>
</div>
        


    /* النوع 1: نزول لتحت */
    .dropdown-down .dropdown-content {
        display: none;
        position: absolute;
        top: 100%;
        left: 0;
    }
    .dropdown-down:hover .dropdown-content {
        display: block;
    }

🔹 النوع 2: القائمة تطلع لفوق (Up)

  • تظهر فوق الزر
  • تستخدم bottom: 100%;

<div class="dropdown-item">
    <h3>▲ طلوع لفوق</h3>
    <div class="dropdown dropdown-up">
        <button class="dropbtn">القائمة ▲</button>
        <div class="dropdown-content">
            <a href="#">الرئيسية</a>
            <a href="#">من نحن</a>
            <a href="#">الخدمات</a>
            <a href="#">اتصل بنا</a>
        </div>
    </div>
</div>
        


    /* النوع 2: طلوع لفوق */
    .dropdown-up .dropdown-content {
        display: none;
        position: absolute;
        bottom: 100%;
        left: 0;
        margin-bottom: 5px;
    }
    .dropdown-up:hover .dropdown-content {
        display: block;
    }

🔹 النوع 3: القائمة من اليمين (Right)

  • تظهر عن يمين الزر
  • تستخدم left: 100%;



<div class="dropdown-item">
    <h3>◀️ من اليمين</h3>
    <div class="dropdown dropdown-right">
        <button class="dropbtn">القائمة ◀️</button>
        <div class="dropdown-content">
            <a href="#">الرئيسية</a>
            <a href="#">من نحن</a>
            <a href="#">الخدمات</a>
            <a href="#">اتصل بنا</a>
        </div>
    </div>
</div>


                

  /* النوع 3: من اليمين */
    .dropdown-right .dropdown-content {
        display: none;
        position: absolute;
        top: 0;
        left: 100%;
        margin-left: 5px;
    }
    .dropdown-right:hover .dropdown-content {
        display: block;
    }

🔹 النوع 4: القائمة ببطء (Slow / With Animation)

  • تظهر وتختفي بحركة سلسة
  • تستخدم opacity و visibility مع transition



<div class="dropdown-item">
    <h3>ببطء (Slow)</h3>
    <div class="dropdown dropdown-slow">
        <button class="dropbtn">القائمة ▼</button>
        <div class="dropdown-content">
            <a href="#">الرئيسية</a>
            <a href="#">من نحن</a>
            <a href="#">الخدمات</a>
            <a href="#">اتصل بنا</a>
        </div>
    </div>
</div>


                

 
    /* النوع 4: ببطء */
    .dropdown-slow .dropdown-content {
        opacity: 0;
        visibility: hidden;
        position: absolute;
        top: 100%;
        left: 0;
        transition: all 0.4s ease;
    }
    .dropdown-slow:hover .dropdown-content {
        opacity: 1;
        visibility: visible;
    }
