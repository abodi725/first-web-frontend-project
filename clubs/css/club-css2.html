شرح خصائص CSS

📝 text-transform: uppercase;

المعنى: يحول كل النص إلى حروف كبيرة (Capital Letters)

الاستخدام: للعناوين أو النصوص التي تريدين إبرازها


.uppercase {
    text-transform: uppercase;
}

📝 letter-spacing: 2px;

المعنى: يضيف مسافة بين الحروف

الاستخدام: لإعطاء مظهر أنيق وجميل للنصوص


                        
            .spacing {
            letter-spacing: 2px;

}

📝 word-spacing: 20px;

المعنى: يضيف مسافة بين الكلمات

الاستخدام: لتوسيع النص وجعله أكثر وضوحاً


.word-space {
    word-spacing: 20px;
}

📝 text-decoration: none;

المعنى: يزيل أي زخرفة من النص (مثل الخط الذي تحت الروابط)

الاستخدام: لإزالة الخط من تحت الروابط (Links)


.no-deco {
    text-decoration: none;
}

📝 الفاصلة (,) بين المحددات

المعنى: تطبق نفس التنسيق على عدة عناصر مختلفة

الاستخدام: لتجنب تكرار الكود


.div1, .div2, .div3 {
    background-color: blue;
    color: white;
}

📝 cursor: pointer;

المعنى: يغير شكل الماوس إلى يد عند المرور على العنصر

الاستخدام: للأزرار والروابط عشان توضح إنه قابل للضغط


.clickable {
    cursor: pointer;
}
