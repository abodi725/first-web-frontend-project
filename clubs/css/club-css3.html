شرح خصائص CSS

min-height: 50000px;

المعنى: يحدد أقل ارتفاع للعنصر (50000px في هذا المثال)

الاستخدام: يعطي مساحة كبيرة للتمرير (scroll) لاختبار تأثيرات الـ position


.parent {
    position: relative;
}

📝 letter-spacing: 2px;

المعنى: يضيف مسافة بين الحروف

الاستخدام: لإعطاء مظهر أنيق وجميل للنصوص


                        
            .spacing {
            letter-spacing: 2px;

}

position: absolute;

المعنى: العنصر يخرج من التدفق الطبيعي للصفحة ويوضع بالنسبة لأقرب عنصر أب عنده position: relative

الخصائص المرافقة: top, bottom, left, right


.one {
    position: absolute;
    top: 20px;
    left: 20px;
}

top, left, bottom, right

المعنى: تحدد المسافة من حواف العنصر الأب

  • top: 20px; → يبعد عن الحافة العلوية 20px
  • left: 20px; → يبعد عن الحافة اليسرى 20px
  • bottom: 0; → يلصق بالحافة السفلية
  • right: 0; → يلصق بالحافة اليمنى

  .one {
    position: absolute;
    top: 20px;
    left: 20px;
}

z-index

المعنى: يحدد ترتيب العناصر فوق بعضها (من الأمام للخلف)

القاعدة: العنصر ذو الرقم الأكبر يظهر فوق العنصر ذو الرقم الأصغر


.one { z-index: 3; }   /* يظهر فوق */
.two { z-index: 2; }
.three { z-index: 1; } /* يظهر تحت */

position: fixed;

المعنى: العنصر يثبت في مكانه حتى عند التمرير

الاستخدام: للقوائم الثابتة أو أزرار العودة للأعلى


.fixed-element {
    position: fixed;
    top: 0;
    left: 0;
}

position: sticky;

المعنى: العنصر يبقى عادي لحد ما يوصل نقطة معينة ثم يثبت

الاستخدام: للهيدر أو القوائم التي تلتصق بالأعلى عند التمرير


sticky-element {
    position: sticky;
    top: 0;
}

::after (العنصر الوهمي)

المعنى: يضيف محتوى وهمي بعد محتوى العنصر الأصلي

الاستخدام: للإضافات الزخرفية مثل الأيقونات أو الخطوط


.box::after {
    content: " ";
    position: absolute;
    width: 70%;
    height: 10px;
    background-color: blueviolet;
    bottom: 0;
    left: 0;
}

transition

المعنى: يضيف حركة سلسة عند تغيير الخاصية

الاستخدام: لجعل التغيرات تبدو احترافية وسلسة


.box:hover::after {
    width: 100%;
    height: 100%;
    transition: 2s;
}
