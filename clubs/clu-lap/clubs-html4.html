📝 الفورم (Forms) في HTML

ما هو الفورم؟

الفورم يستخدم لجمع بيانات من المستخدم مثل: الاسم، البريد، كلمة السر، وغيرها.

عناصر الفورم الأساسية:

  • <form> : يبدأ الفورم
  • <input> : حقل إدخال (نص، بريد، كلمة سر، إلخ)
  • <label> : نص وصفي للحقل
  • <textarea> : مساحة نصية كبيرة
  • <select> : قائمة منسدلة
  • <option> : خيار داخل القائمة
  • <button> : زر

أنواع الـ Input:

  • type="text" : نص عادي
  • type="email" : بريد إلكتروني
  • type="password" : كلمة سر (تظهر كنقاط)
  • type="number" : أرقام فقط
  • type="tel" : رقم هاتف
  • type="date" : اختيار تاريخ
  • type="radio" : اختيار واحد فقط
  • type="checkbox" : اختيار متعدد
  • type="submit" : زر إرسال
  • type="reset" : زر مسح
  • type="color" : اختيار لون
  • type="range" : شريط تمرير
  • type="file" : رفع ملف

خصائص مهمة للـ Input:

  • placeholder : نص تلميحي داخل الحقل
  • required : الحقل إجباري
  • readonly : للقراءة فقط
  • disabled : معطل (ما يقدر يكتب فيه)
  • value : قيمة افتراضية
  • min / max : أقل وأكبر قيمة للأرقام

<!-- Basic Form -->
<form action="#" method="post">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" placeholder="Enter your name" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" placeholder="example@email.com">
    
    <label for="password">Password:</label>
    <input type="password" id="password" name="password">
    
    <input type="submit" value="Submit">
    <input type="reset" value="Reset">
</form>

<!-- Textarea (Large text area) -->

<!-- Number Input with min/max -->
<label for="age">Age (18-60):</label>

<!-- Date Input -->

<!-- Range Slider -->
<label for="volume">Volume:</label>

<input type="file" id="file" name="file">
