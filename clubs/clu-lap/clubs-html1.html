1. العناوين (Headings)

العناوين في HTML تستخدم لتنظيم المحتوى وترتيب الصفحة، مثل عناوين الكتب والفصول. هناك 6 مستويات للعناوين تبدأ من h1 وتنتهي بـ h6.

عنوان h1 هو الأكبر والأهم، ويستخدم مرة واحدة فقط في الصفحة للعنوان الرئيسي. عنوان h2 يأتي بعده للقسم الرئيسي، ثم h3 للأقسام الفرعية، وهكذا حتى h6 الأصغر.

مثال على العناوين: h1 لعنوان الموقع، h2 لعنوان القسم، h3 لعنوان الموضوع داخل القسم، h4 و h5 و h6 للتفاصيل الأقل أهمية.

العناوين تجعل الصفحة منظمة وسهلة القراءة، وتساعد محركات البحث في فهم محتوى صفحتك.

                        
 <h1>موقع تعليم البرمجة</h1>
<p>مرحباً بك في موقعنا التعليمي.</p>

 <h2>دروس </h2>
  <p>ستتعلم في هذا القسم أساسيات </p>

 <h3>العناوين في HTML</h3>
 <p>هناك 6 مستويات للعناوين...</p>

2.تنسيق النصوص في HTML

  • <b> : نص غامق - للتنسيق فقط
  • <strong> : نص مهم - للأهمية
  • <i> : نص مائل - للتشديد
  • <mark> : نص مظلل - للتمييز
  • <u> : نص تحته خط - للتنبيه
  • <small> : نص صغير - للتعليقات
  • <del> : نص محذوف - للإشارة للحذف
  • <sub> : H2O - أسفل السطر
  • <sup> : 22 - فوق السطر

 <b>نص غامق</b>
 <strong>نص مهم</strong>
  <i>نص مائل</i>
    <mark>نص مظلل</mark>
<u>نص تحته خط</u>
  <small>نص صغير</small>
   <del>نص محذوف</del>
   H<sub>2</sub>O
 2<sup>2</sup> = 4

3. الروابط في HTML

  • <a> : عنصر الرابط
  • href : تحدد عنوان الرابط (مثل https://google.com)
  • target="_blank" : يفتح الرابط في نافذة جديدة
  • target="_self" : يفتح في نفس النافذة (الافتراضي)
  • title : نص يظهر عند تمرير الماوس
  • mailto: : لإنشاء رابط بريد إلكتروني


  <!-- رابط عادي -->
   <a href="https://google.com">إذهب إلى Google</a>
   <!-- رابط يفتح في نافذة جديدة -->
   <a href="https://google.com" target="_blank">Google (نافذة جديدة)</a>

 <!-- رابط مع عنوان -->
<a href="https://google.com" title="زيارة Google">Google</a>

<!-- رابط بريد إلكتروني -->
 <a href="mailto:example@email.com">example@email.com</a>

  <!-- رابط داخلي (داخل نفس الموقع) -->
<a href="about.html">عن الموقع</a>

 <!-- رابط ب أيقونة -->
 <a href="#">📧 example@email.com</a>

4. الصور في HTML

  • <img> : عنصر الصورة (لا يحتاج قفل)
  • src : مصدر الصورة (مسارها)
  • alt : نص بديل إذا ما تحمّلت الصورة
  • width : عرض الصورة بالبكسل أو النسبة
  • height : ارتفاع الصورة
  • title : نص يظهر عند تمرير الماوس

<!-- صورة من رابط خارجي -->
<img src="https://picsum.photos/200/150" alt="صورة عشوائية">

<!-- صورة مع تحديد الحجم -->
<img src="photo.jpg" alt="وصف الصورة" width="300" height="200">

<!-- صورة مع عنوان منبثق -->
<img src="logo.png" alt="شعار الموقع" title="شعار جودي">

<!-- صورة كنسبة مئوية (responsive) -->
<img src="banner.jpg" alt="بانر" style="width: 100%;">

<!-- صورة داخل رابط (تنقر تودي لصفحة) -->
<a href="https://example.com">
    <img src="button.png" alt="زر">
</a>
