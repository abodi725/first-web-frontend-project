📦 الحاويات في HTML (Div & Span)

ما هي الحاويات؟

الحاويات تستخدم لتجميع العناصر وتنظيمها داخل الصفحة.

الفرق بين Div و Span:

  • <div> : عنصر كتلة (Block) - يأخذ عرض كامل الصفحة ويبدأ سطر جديد
  • <span> : عنصر سطري (Inline) - يأخذ مساحة النص فقط

متى تستخدمين كل عنصر؟

  • Div: لتجميع أقسام كاملة (header, footer, sidebar)
  • Span: لتنسيق جزء صغير من النص (لون، حجم، خلفية)

<!-- Div Example (block element) -->
<div style="background-color: #6C63FF; padding: 20px; margin: 10px;">
    <h3>This is a Div</h3>
    <p>Div takes the full width and starts on a new line.</p>
</div>

<!-- Span Example (inline element) -->
<p>
    This is normal text. 
    <span style="color: #FF6584; font-weight: bold;">This text is inside a span</span>
    and stays in the same line.
</p>

<!-- Multiple Divs for layout -->
<div style="display: flex; gap: 20px;">
    <div style="background: #0A0F1E; padding: 20px; border-radius: 10px;">
        <h3>Left Box</h3>
        <p>Content here</p>
    </div>
    <div style="background: #0A0F1E; padding: 20px; border-radius: 10px;">
        <h3>Right Box</h3>
        <p>Content here</p>
    </div>
</div>

<!-- Nested Divs -->
<div class="container" style="border: 2px solid #6C63FF; padding: 20px;">
    <h2>Outer Div</h2>
    <div style="background: rgba(108,99,255,0.1); padding: 15px;">
        <p>Inner Div with different background</p>
    </div>
</div>

<!-- Span inside paragraph -->
<p>
    <span style="background: yellow; color: black;">Highlighted text</span>
    is very important.
</p>

<!-- Div for styling group of elements -->
<div class="card" style="border: 1px solid #FF6584; border-radius: 15px; padding: 20px; width: 300px;">
    <h3>Card Title</h3>
    <p>This is a card created with div.</p>
    <button style="background: #6C63FF; color: white; padding: 8px 16px;">Click Me</button>
</div>

🧱 العناصر الدلالية في HTML (Semantic Elements)

ما هي العناصر الدلالية؟

عناصر تحمل معنى واضح لمحركات البحث والمطورين، تصف محتوى الصفحة بشكل مفهوم.

العناصر الدلالية الرئيسية:

  • <header> : رأس الصفحة (شعار، عنوان، قائمة)
  • <nav> : قائمة الروابط الرئيسية
  • <main> : المحتوى الرئيسي للصفحة
  • <section> : قسم من المحتوى
  • <article> : مقال أو محتوى منفصل
  • <aside> : محتوى جانبي (شريط جانبي)
  • <footer> : تذييل الصفحة (حقوق النشر، روابط)
  • <figure> : صورة مع شرحها
  • <figcaption> : شرح الصورة
  • <details> : قائمة قابلة للطي
  • <summary> : عنوان القائمة القابلة للطي

لماذا نستخدم العناصر الدلالية؟

  • ✅ تحسين SEO (محركات البحث)
  • ✅ تسهيل قراءة الكود
  • ✅ مساعدة قارئات الشاشة للمكفوفين
  • ✅ تنظيم أفضل للصفحة

<!-- Basic HTML Structure with Semantic Elements -->
<body>
    <header>
        <h1>My Website</h1>
        <p>Welcome to my site</p>
    </header>

    <nav>
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Contact</a>
    </nav>

    <main>
        <section>
            <h2>Latest Articles</h2>
            
            <article>
                <h3>Article Title 1</h3>
                <p>This is the content of the first article.</p>
            </article>
            
            <article>
                <h3>Article Title 2</h3>
                <p>This is the content of the second article.</p>
            </article>
        </section>

        <aside>
            <h3>Sidebar</h3>
            <p>Related links and ads go here.</p>
        </aside>
    </main>

    <footer>
        <p>&copy; 2025 My Website. All rights reserved.</p>
    </footer>
</body>

<!-- Figure and Figcaption -->
<figure>
    <img src="photo.jpg" alt="Description">
    <figcaption>This is a caption for the image</figcaption>
</figure>

<!-- Details and Summary (Collapsible content) -->
<details>
    <summary>Click to see more information</summary>
    <p>This content is hidden until you click the summary above.</p>
</details>

<!-- Mark for highlighting -->
<p>This is <mark>important text</mark> that is highlighted.</p>

<!-- Time element -->
<p>Published on <time datetime="2025-01-15">January 15, 2025</time></p>
