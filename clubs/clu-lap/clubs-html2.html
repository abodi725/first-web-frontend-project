📋 القوائم في HTML

أنواع القوائم:

  • <ul> : قائمة غير مرتبة - تظهر بنقاط
  • <ol> : قائمة مرتبة - تظهر بأرقام أو حروف
  • <li> : عنصر داخل القائمة

<!-- قائمة غير مرتبة (نقاط) -->
<h3>لغات البرمجة:</h3>
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
    <li>Python</li>
</ul>

<!-- قائمة مرتبة (أرقام) -->
<h3>خطوات تعلم البرمجة:</h3>
<ol>
    <li> HTML</li>
    <li> CSS</li>
    <li> JavaScript</li>
    <li>project </li>
</ol>

📋 القوائم في HTML

أنواع الترقيم في ol:

  • type="1" : أرقام 1, 2, 3
  • type="A" : حروف كبيرة A, B, C
  • type="a" : حروف صغيرة a, b, c
  • type="I" : أرقام رومانية I, II, III


<!-- قائمة مرتبة بحروف كبيرة -->
<ol type="A">
    <li>one</li>
    <li>name</li>
    <li>age</li>
</ol>

<!-- قائمة مرتبة بأرقام رومانية -->
<ol type="I">
    <li>name </li>
    <li>age </li>
    <li>joudi </li>
</ol>

<!-- قائمة بدون نقاط (للقوائم الأفقية) -->
<ul style="list-style-type: none;">
    <li>home</li>
    <li>about </li>
    <li> tell</li>
</ul>

📊 الجداول في HTML

عناصر الجدول:

  • <table> : يبدأ الجدول
  • <tr> : Table Row - صف في الجدول
  • <th> : Table Header - خلية عنوان (غامق)
  • <td> : Table Data - خلية عادية
  • border : لتحديد خطوط الجدول

<!-- جدول بسيط -->
<table border="1">
    <tr>
        <th>name</th>
        <th>age</th>
        <th>city</th>
    </tr>
    <tr>
        <td>ahmd</td>
        <td>25</td>
        <td>homs</td>
    </tr>
    <tr>
        <td>sara</td>
        <td>22</td>
        <td>hama</td>
    </tr>
</table>

📊 الجداول في HTML

عناصر الجدول:

  • colspan : دمج أعمدة أفقياً



<!-- جدول مع دمج الأعمدة (colspan) -->
<table border="1">
    <tr>
        <th>name</th>
        <th colspan="2">number </th>
    </tr>
    <tr>
        <td>ahmad</td>
        <td>ahmed@email.com</td>
        <td>+123456789</td>
    </tr>
</table>

  • rowspan : دمج صفوف عمودياً
